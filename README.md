# Plastic Shredder Machine – Mechanical Design

This project presents the complete mechanical design of a dual-shaft plastic shredder machine developed in SolidWorks.

## Description
The machine consists of two counter-rotating shredding shafts equipped with cutting blades, mounted on bearings and supported by a rigid steel frame. The system is designed for plastic size reduction in recycling applications.

The shredder is driven by electric motors coupled to the shafts through gearboxes, providing the high torque required for shredding operations.

## Key Features
- Dual-shaft shredding mechanism
- Counter-rotating shafts
- Modular blade design
- Bearing-supported shafts
- Rigid structural frame
- Motorized drive system
